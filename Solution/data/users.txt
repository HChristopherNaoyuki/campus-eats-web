IMPORTANT: DEMONSTRATION DATA

The ten accounts listed in this file are fabricated demonstration data.

addresses can receive mail. The passwords are public. They must never

    Solution/sql/seed.php

Run the seed script from the project root:

================================================================================
How to Sign In
================================================================================

The sign-in page accepts any of the following as the identifier:

    - The email address, for example amara.nkosi@campuseats.test
    - The username, for example amara.nkosi
    - The 16-character unique ID, with or without hyphens,
      for example ADMN4K7P2Q9XRT5M or ADMN-4K7P-2Q9X-RT5M

The password is the one listed above for the account.

================================================================================
Password Policy
================================================================================

Every password in this file satisfies the application policy:

    - At least eight characters long.
    - Contains at least one uppercase letter.
    - Contains at least one lowercase letter.
    - Contains at least one digit.
    - Contains at least one special symbol.

The password stored in the database is a bcrypt hash produced by
password_hash() at cost factor 12. The plain-text values exist only in
this file and in demo_accounts.php. They are never stored in the
database.

================================================================================
Reminder
================================================================================

Before deploying this application to any host that is reachable from a
network:

    1. Delete this file.
    2. Delete or empty Solution/config/demo_accounts.php.
    3. Do not run Solution/sql/seed.php on that host.
    4. Create real accounts through the registration page.
